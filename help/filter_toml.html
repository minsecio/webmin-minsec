Custom filter TOML

Define how Minsec finds and recognizes failed activity. A filter needs a name and one or more patterns, plus file paths or journal selectors that identify its log source.

name = "myapp"
files = ["/var/log/myapp.log"]
prefilter = ["login failed"]
patterns = ['login failed for <F-USER>\S+</F-USER> from <HOST>']

The filter must also be enabled in Minsec configuration with [filters.myapp] and enabled = true.
