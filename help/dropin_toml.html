Configuration TOML

Enter Minsec configuration using the same tables accepted by minsec.toml. Drop-ins are merged over the main configuration.

Use [defaults] for global policy and backend settings, or [filters.NAME] to enable a filter and override its policy or log sources.

[defaults]
maxretry = 5
bantime = "1h"

[filters.sshd]
enabled = true
maxretry = 3
minsec(8)
